One letter, nothing else: A for coffee. The program writes exactly one character to `/output/entry.txt` — the letter whose drink feels most vivid, funniest and truest under the judge's criteria (vivid first, then funny, then true). Coffee wins on vividness: dark, bitter, steaming, a jolt — the more alive answer — and it owns the jokes besides.

## Run it

```sh
python3 main.py
```
